A **YouTube Frontend Clone** project built using **HTML and CSS**, focusing on recreating the layout, UI structure, and visual components of YouTube’s homepage and related sections. This project is ideal for learning frontend development, layout design, and UI structuring.

---

## 📌 Project Description

This project is a static frontend clone of YouTube, designed to replicate:

* Homepage layout
* Video thumbnails grid
* Navigation bar
* Sidebar menu
* Header components
* Icons and UI elements

It is created for:

* Learning frontend development
* UI/UX practice
* College projects
* Portfolio showcase

---

##  Features

* 🎯 Clean UI layout
